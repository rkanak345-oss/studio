# **App Name**: RefRevenue

## Core Features:

- User Authentication: Allow users to register and login to the application using a mobile number and OTP verification.
- Referral Code Display: Display the user's referral code and a shareable link for easy sharing.
- Wallet Balance Display: Show the user's current wallet balance and a button to initiate withdrawals.
- Referral List: Present a list of users who have been referred by the current user, along with their registration date and earned amount.
- Transaction History: Display a history of transactions and withdrawals made by the user.
- AI-Powered Referral Messaging: Based on current marketing trends, generate personalized messages the user can copy/paste to their social media, to help incent referral signups. This is achieved by giving a tool to an LLM that searches the web, retrieves trends, and incorporates those trends into a message for the user.

## Style Guidelines:

- Primary color: Dark blue (#0F172A) to convey trust and stability.
- Background color: Light gray (#F1F5F9), a desaturated variant of the primary, to ensure focus remains on the content.
- Accent color: Bright orange (#F97316) to draw attention to important actions.
- Body and headline font: 'Inter' (sans-serif) for a clean and modern look.
- Use simple, outlined icons to represent different features and actions.
- Use a grid-based layout to organize content effectively across different screen sizes.
- Subtle transitions and animations to provide feedback and enhance user experience.
